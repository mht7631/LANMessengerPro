# LAN Messenger Pro — وضعیت توسعه

پیام‌رسان دسکتاپ ویندوز با Python و PySide6 برای شبکه داخلی (LAN).

## قابلیت‌های پیاده‌سازی‌شده

- شناسه و گواهی هویتی پایدار ECDSA برای هر نصب
- کشف دستگاه‌ها با UDP Multicast و Broadcast و نمایش حضور آنلاین
- Pairing دستی دوطرفه با تبادل گواهی و تطبیق مستقل اثرانگشت SHA-256
- ارتباط پیام و فایل روی TLS 1.2 یا بالاتر؛ دستگاه Pair‌نشده پذیرفته نمی‌شود
- تاریخچه SQLite جداگانه برای هر مخاطب
- تأیید تحویل پیام و صف پیام‌های خروجی برای تلاش مجدد
- ارسال فایل تکی با درخواست تأیید از گیرنده
- ارسال پوشه با حفظ ساختار زیرپوشه‌ها و یک‌بار تأیید گیرنده برای کل پوشه
- بررسی اندازه و SHA-256 فایل پیش از انتشار در پوشه دریافت
- پوشه دریافت مجزا برای هر فرستنده و جلوگیری از بازنویسی فایل موجود
- ثبت تاریخچه انتقال‌ها در SQLite
- تم روشن/تیره، System Tray، تنظیم نام نمایشی و مسیر دریافت

## محدودیت‌های فعلی انتقال

- حداکثر اندازه هر فایل: ۵۱۲ مگابایت
- حداکثر هر پوشه: ۱۰۲۴ فایل و مجموع ۲ گیگابایت
- فایل‌های یک پوشه به‌ترتیب ارسال می‌شوند؛ ادامه خودکار انتقال قطع‌شده هنوز وجود ندارد
- گفتگوی گروهی، نشانگر تایپ، رسید خواندن، ویرایش پیام و امضای دیجیتال فایل اجرایی هنوز پیاده‌سازی نشده‌اند
- پیام‌های کشف UDP احراز هویت نمی‌شوند و فقط برای پیدا کردن دستگاه‌ها هستند؛ محتوای چت و فایل از کانال TLS جفت‌شده عبور می‌کند
- Pairing باید روی هر دو دستگاه و با بررسی اطلاعات از یک کانال مستقل و مورد اعتماد انجام شود. پورت برنامه را به اینترنت عمومی باز نکنید.

## اجرا در PowerShell

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
$env:PYTHONPATH = "src"
python -m lanmessenger
```

برنامه را روی حداقل دو رایانه در یک شبکه Private اجرا کنید. در صورت نمایش پیام Windows Firewall، فقط دسترسی شبکه Private را مجاز کنید.

## محل داده‌ها

در مسیر `%LOCALAPPDATA%\LANMessengerPro\`:
- `messenger.db` — مخاطبین، تاریخچه پیام و تاریخچه انتقال‌ها
- `config.json` — شناسه، نام نمایشی، تم و مسیر دریافت
- `identity\` — کلید خصوصی و گواهی هویت دستگاه
- `Received\<شناسه-فرستنده>\` — فایل‌های دریافتی؛ پوشه‌های ارسالی ساختار اصلی خود را حفظ می‌کنند

## ساخت نسخه Portable

```powershell
python -m pip install nuitka
python build.py
```

ساخت EXE و اجرای واقعی روی چند رایانه و شبکه‌های مختلف هنوز باید جداگانه اعتبارسنجی شود.
