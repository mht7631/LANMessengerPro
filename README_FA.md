# LAN Messenger Pro — v0.1

نمونه اجرایی رابط کاربری و لایه ذخیره‌سازی محلی بر پایه Python و PySide6.

## وضعیت این نسخه
این نسخه یک پوسته دسکتاپ قابل اجرا برای شروع پروژه است:
- رابط کلاسیکِ مدرن با فهرست کاربران و پنجره گفتگو
- تم روشن و تیره
- تنظیم نام نمایشی خود کاربر
- پنجره مستقل History Viewer
- انتخاب پوشه اصلی دریافت فایل
- ساخت پوشه اختصاصی برای هر فرستنده
- ذخیره تنظیمات، مخاطبین و پیام‌های نمونه در SQLite
- System Tray

**هنوز شبکه P2P، کشف خودکار کاربران، Pairing، رمزنگاری شبکه و انتقال واقعی فایل پیاده‌سازی نشده‌اند.** مخاطبین فعلی داده نمونه هستند تا رابط و گردش‌کارها قابل بررسی باشند. تغییر نام در این نسخه محلی ذخیره می‌شود؛ انتشار نام برای سایر دستگاه‌ها در مرحله شبکه پیاده‌سازی خواهد شد.

## نیازمندی‌ها
- Windows 10/11
- Python 3.11 یا جدیدتر (پیشنهاد: Python 3.13)

## اجرا در حالت توسعه
```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python -m lanmessenger
```

## ساختار داده
داده‌ها در مسیر `%LOCALAPPDATA%\\LANMessengerPro\\` ذخیره می‌شوند:
- `messenger.db`
- `config.json`
- `Received\\<SenderName>\\`

## ساخت Portable EXE
```powershell
pip install nuitka
python build.py
```
خروجی در پوشه `dist` ساخته می‌شود. این اسکریپت برای Windows طراحی شده و باید روی Windows اجرا شود.

## مرحله بعد
1. UDP discovery برای شبکه محلی
2. شناسه ثابت دستگاه و pairing دوطرفه
3. TCP/TLS و پروتکل نسخه‌بندی‌شده
4. پیام خصوصی و گروهی
5. تاریخچه همگام‌شده و صف تحویل
6. انتقال فایل امن و قابل ادامه
