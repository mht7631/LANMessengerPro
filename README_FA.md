# LAN Messenger Pro — وضعیت توسعه v0.2-dev

پیام‌رسان دسکتاپ Windows با Python و PySide6، با هدف کارکرد در شبکه داخلی و بدون نیاز به اینترنت.

## پیاده‌سازی‌شده
- رابط دسکتاپ مدرن با تم روشن و تیره
- شناسه پایدار برای هر دستگاه
- کشف کاربران شبکه با UDP Multicast و Broadcast
- نمایش خودکار کاربران آنلاین و آفلاین و حذف وضعیت آنلاین پس از Timeout
- انتشار تغییر نام نمایشی برای سایر کلاینت‌های فعال
- SQLite برای مخاطبین و تاریخچه جداگانه هر مخاطب
- پنجره مستقل History Viewer
- انتخاب مسیر اصلی دریافت فایل
- System Tray و گزینه شروع به‌صورت Minimized

## پیاده‌سازی‌شده در مرحله ارتباط
- شنونده TCP با TLS 1.2 یا بالاتر و گواهی هویتی پایدار ECDSA برای هر نصب
- Pairing دستی با تبادل شناسه دستگاه، گواهی PEM و تطبیق اثرانگشت SHA-256 از یک کانال مورد اعتماد
- احراز هویت دوطرفه گواهی‌ها و رد دستگاه‌هایی که قبلاً مورد اعتماد قرار نگرفته‌اند
- ارسال پیام متنی به مخاطب آنلاین و دریافت ACK؛ پیام‌های دریافتی در تاریخچه SQLite ذخیره می‌شوند
- جلوگیری از ثبت دوباره پیام‌های دریافتی با شناسه پیام

## هنوز پیاده‌سازی نشده
- انتقال واقعی فایل و ساخت پوشه اختصاصی فرستنده
- گفتگوهای گروهی، وضعیت تایپ و رسید خواندن
- بسته‌بندی نهایی و امضای کد

**محدودیت‌ها:** کشف دستگاه‌ها با UDP همچنان رمزنگاری و احراز هویت نشده است و فقط برای یافتن دستگاه‌ها به کار می‌رود؛ پیام‌ها از کانال TLS استفاده می‌کنند. Pairing فعلاً دستی است: هر دو کاربر باید شناسه، گواهی و اثرانگشت یکدیگر را از کانالی مستقل مبادله و بررسی کنند. این نسخه هنوز برای شبکه‌های عمومی مناسب نیست و نباید پورت‌ها را به اینترنت باز کنید.

## اجرا در PowerShell
```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
$env:PYTHONPATH = "src"
python -m lanmessenger
```

برنامه را روی حداقل دو کامپیوتر متصل به یک LAN اجرا کنید. در صورت نمایش پیام Windows Defender Firewall، دسترسی را فقط برای شبکه Private مجاز کنید. دستگاه‌ها باید پس از چند ثانیه در فهرست ظاهر شوند.

## محل داده‌ها
در مسیر %LOCALAPPDATA%\LANMessengerPro\:
- messenger.db — مخاطبین و تاریخچه SQLite
- config.json — نام نمایشی، شناسه پایدار، تم و مسیر دریافت
- Received\ — ریشه پوشه دریافت

## مشخصات Discovery
- UDP Port: 47777
- Multicast: 239.255.77.77
- فاصله اعلان: ۳ ثانیه
- زمان انقضای Peer: ۱۲ ثانیه
- نسخه پروتکل: 1

مرحله بعد: Pairing احراز هویت‌شده، پیام‌رسانی TCP رمزنگاری‌شده با TLS، صف ارسال و تأیید تحویل، سپس انتقال فایل قابل ادامه.

## Pairing و تست چت
1. برنامه را روی هر دو رایانه در یک شبکه Private اجرا کنید.
2. در هر دو دستگاه روی **Pair device** بزنید.
3. شناسه دستگاه، اثرانگشت SHA-256 و گواهی PEM هر دستگاه را از طریق کانالی مستقل و مورد اعتماد مبادله کنید.
4. در دستگاه اول اطلاعات دستگاه دوم و در دستگاه دوم اطلاعات دستگاه اول را وارد کنید. اثرانگشت‌ها را مستقل از همین شبکه مقایسه کنید.
5. پس از Pair شدن دوطرفه، مخاطب باید با علامت قفل نمایش داده شود؛ گفتگوی متنی را شروع کنید.
6. Windows Firewall را فقط برای شبکه Private و برنامه LAN Messenger Pro مجاز کنید.

پورت TCP پیش‌فرض پیام‌رسانی: 47888. پورت UDP کشف: 47777.
