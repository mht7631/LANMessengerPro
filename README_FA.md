# LAN Messenger Pro — وضعیت توسعه v0.2-dev

پیام‌رسان دسکتاپ Windows با Python و PySide6، با هدف کارکرد در شبکه داخلی و بدون نیاز به اینترنت.

## پیاده‌سازی‌شده
- رابط دسکتاپ مدرن با تم روشن و تیره
- شناسه پایدار برای هر دستگاه
- کشف کاربران شبکه با UDP Multicast و Broadcast
- نمایش خودکار کاربران آنلاین و آفلاین و حذف وضعیت آنلاین پس از Timeout
- انتشار تغییر نام نمایشی برای سایر کلاینت‌های فعال
- SQLite برای مخاطبین و تاریخچه جداگانه هر مخاطب
- پنجره مستقل History Viewer
- انتخاب مسیر اصلی دریافت فایل
- System Tray و گزینه شروع به‌صورت Minimized

## هنوز پیاده‌سازی نشده
- انتقال پیام با TCP/TLS و تأیید تحویل
- Pairing و مدیریت دستگاه‌های مورد اعتماد
- انتقال واقعی فایل و ساخت پوشه اختصاصی فرستنده
- گفتگوهای گروهی، وضعیت تایپ و رسید خواندن
- بسته‌بندی نهایی و امضای کد

**محدودیت مهم این مرحله:** در حال حاضر فقط اطلاعات حضور دستگاه (شناسه، نام نمایشی و نسخه پروتکل) از شبکه پخش می‌شود؛ متن پیام و فایل ارسال نمی‌شود. Discovery با UDP رمزنگاری یا احراز هویت نشده است؛ فقط در شبکه خصوصی مورد اعتماد اجرا شود و پورت آن را به اینترنت باز نکنید.

## اجرا در PowerShell
```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
$env:PYTHONPATH = "src"
python -m lanmessenger
```

برنامه را روی حداقل دو کامپیوتر متصل به یک LAN اجرا کنید. در صورت نمایش پیام Windows Defender Firewall، دسترسی را فقط برای شبکه Private مجاز کنید. دستگاه‌ها باید پس از چند ثانیه در فهرست ظاهر شوند.

## محل داده‌ها
در مسیر %LOCALAPPDATA%\LANMessengerPro\:
- messenger.db — مخاطبین و تاریخچه SQLite
- config.json — نام نمایشی، شناسه پایدار، تم و مسیر دریافت
- Received\ — ریشه پوشه دریافت

## ساخت نسخه Portable
```powershell
pip install nuitka
python build.py
```
